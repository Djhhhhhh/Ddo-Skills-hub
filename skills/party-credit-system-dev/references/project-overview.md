# 项目概览

## 项目背景

党员信用系统是一个线上填报与审核平台，用于替代原有纸质表单与分散 Excel 的工作方式，将党员信用指标的填报、审核、统计与汇总统一到同一个 Web 系统中。

## 支持角色

### 普通党员

- 填报信用指标
- 查看基础项
- 自选填报加分项与减分项
- 上传 PDF 附件
- 保存与提交申报
- 查看个人填报记录
- 导出申报表
- 修改密码

### 党支部

- 审核党员填报内容
- 单条审批
- 批量审批
- 调整基础项分值
- 驳回申报
- 管理党员账号
- 批量导入导出账号
- 查看填报进度与奖惩统计
- 管理党支部工作纪实

### 党委办公室

- 执行跨支部的全量审核管理
- 查看、审批、删除、批量审批与导出审核数据
- 维护指标体系，包括新增、修改、删除、导入、导出
- 管理党支部账号
- 查看全院数据总览
- 管理跨支部工作纪实，包括筛选、搜索、代发、修改、删除

## MVP 范围

- 默认实现说明书中已明确列出的全部需求。
- 默认不增加说明书之外的扩展功能。

## 典型任务映射

- 个人填报、附件上传、申报表导出等需求，归属于普通党员角色。
- 审批流程、基础分调整、党员账号管理等需求，归属于党支部角色。
- 跨支部监督、指标体系维护、全院统计总览等需求，归属于党委办公室角色。
